# FFmpeg 播放引擎（音频完整版）

完整保留 FFmpeg 内置 200 个音频解码器，适合小众音频格式。

两个版本共享播放和文件兼容修复，请选择其中一个启用。精简版保留原有 MP3、FLAC、AAC、ALAC、Vorbis、Opus、APE、WavPack、AC-3/E-AC-3 及常见 PCM 范围；音频完整版扩展到 FFmpeg 7.1.1 内置 200 个音频解码器及全部输入封装/解析器，均不含视频解码和模型。

1.4.6 修复有效 FLAC 音频前夹杂大量额外数据时无法播放：按头部 CRC8 和完整音频帧 CRC16 校验恢复起点，只调整只读流映射，不修改原文件。两版不互相依赖，通过相同公开播放服务接管播放。

FFmpeg: LGPL-2.1-or-later。源码及构建脚本位于本仓库 plugins/ffmpeg。
