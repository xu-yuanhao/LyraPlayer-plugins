## 1.4.6：纠正并复现首帧恢复

此前只跑默认 FFmpeg 读取路径，用户文件输出零样本，不能据此判定原文件没有可播放音频。继续对照系统可播放行为后，确认元数据结束和有效首帧之间存在额外数据。通用恢复扫描验证首帧 CRC8、完整帧 CRC16 及下一帧头，只读重映射去除间隙。该样本恢复后的全部 PCM 与原始 STREAMINFO MD5 一致，255 秒共 11245500 个 44.1kHz 立体声帧。

`flac_gap_test.cpp` 覆盖无间隙、短间隙、64KiB 边界、16MiB 间隙及伪帧头，均通过。`LYRA_TEST_FLAC_FILE` 可给设备引擎回归测试传入不公开的本地样本；启播、中间跳转和曲尾跳转均通过。精简版保留原 20 个解码器，完整版保留 200 个，两版都包含恢复修复。不会修改、提交或发布用户音频。
