# 字体自定义

为 Lyra Player 增加原有的详细字体设置。安装并启用后，设置页出现“字体”入口，使用主程序相同的卡片、开关、滑块和确认框。

支持跟随系统字体、自动选择或推荐字体、导入 TTF/OTF/TTC 字体、管理已安装字体及全部字重，以及通用界面、播放歌名、歌手、时间、迷你和展开歌词的字号和粗体调整。可以跟随系统字号参数，也可以确认恢复官方默认值；重置不会删除导入文件。导入采用有上限、超时及元数据校验的后台任务，删除仅允许插件私有目录中的已安装字体。

需要支持公共设置页消息接口（ID 26）及 Android 平台契约 8 的新版主程序。旧版主程序会拒绝加载，不会出现残缺界面。插件不附带字体文件。原有字体设置和已导入字体继续使用，无需重新导入。

不安装此插件，主程序仍按原有规则扫描并自动选择合适的默认字体，保持官方默认字号和字重。插件仅通过已公布的配置、设置页及 Android Activity 接口工作，不依赖宿主的私有 C++ 符号。
