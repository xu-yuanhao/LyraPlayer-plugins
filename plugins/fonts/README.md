# 字体自定义

为 Lyra Player 增加原有的详细字体设置。安装并启用后，设置页出现“字体”入口，使用主程序相同的卡片、开关、滑块和确认框。

支持跟随系统字体、自动选择或推荐字体、导入 TTF/OTF/TTC 字体、管理已安装字体及全部字重，以及通用界面、播放歌名、歌手、时间、迷你和展开歌词的字号和粗细调整。可以跟随系统字号参数，也可以确认恢复官方默认值；重置不会删除导入文件。导入采用有上限、超时及元数据校验的后台任务，删除仅允许插件私有目录中的已安装字体。

需要包含字体自动粗细适配与数值字重配置的新版主程序，并支持公共设置页消息接口（ID 26）和 Android 平台契约 8。插件不附带字体文件。原有字体设置和已导入字体继续使用，无需重新导入。

粗细滑条有安全范围；新字体默认自动适配粗细，调整后按字体保留手动设置，切换回来不会覆盖。恢复默认会清除这些手动设置，但不删除字体文件。

不安装此插件，主程序仍会自动选择默认字体和适合它的粗细，保留官方默认字号。插件仅通过已公布的配置、设置页及 Android Activity 接口工作，不依赖宿主的私有 C++ 符号。
