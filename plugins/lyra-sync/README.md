# Lyra Player 同步插件

作者 chun。适用于 Android arm64-v8a，使用 Lyra 插件 ABI 3 和 Android 平台接口 v1。两台设备可通过同一局域网直接传输音乐。

在接收端打开接收模式，再在发送端填写接收端地址、端口和配对密钥，选择曲目并发起传输。首次配对需要接收端确认。传输使用分块校验，接收端在完整文件通过 SHA-256 校验后提交。

当前版本供维护者审核与真机试装。桌面测试覆盖三首歌曲场景下的进程重启和部分文件补传。已发布的文件可能再次传输，接收端对相同内容执行幂等提交。超过单批上限的任务在首批中途硬杀后的恢复尚未通过验收。宿主设置页面、目录授权、曲库可见与播放仍待 Android 真机验证。

在仓库根目录执行 `plugins/lyra-sync/build.sh`。需要 NDK r28b（28.2.13676358）及 Python 3.11 或更新版本。可用 `LYRA_NDK_HOME` 指向已安装的 NDK。脚本将安装包和对应源码附件放到 `dist/`。
